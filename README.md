# Bounce Back

一款使用 Godot 4 製作的 2D 小遊戲：金幣隨機生成、彈簧墊彈跳、尖刺陷阱。

## 內容
- 金幣（coin.tscn）：旋轉動畫，隨機生成
- 彈簧墊（spring.tscn）：踩上去播放「壓平 → 伸長 → 壓平」動畫並彈起
- node_2d.gd：在地圖範圍內隨機生成金幣與彈簧，彼此保持距離

## 如何執行
1. 安裝 Godot 4.x
2. 用 Godot 開啟本資料夾的 project.godot
3. 按 F5 執行

## 素材來源
- 背景 / 尖刺 / 彈簧：尖刺素材包（請見 尖刺/ 資料夾內的 license.txt）
- 金幣：自製
